# API

`GET /health` and `GET /readiness` report service/configuration status. `GET /v1/infrastructure/workers` and `/v1/infrastructure/queue` expose operational state. `POST /v1/architectures/validate` accepts a strict Architecture JSON document and returns its canonical hash plus analytical metrics. `POST /v1/architectures`, `GET /v1/architectures`, and `GET /v1/architectures/{architecture_id}` provide the local registry surface. `POST /v1/searches` creates a budgeted search session; status and cancellation are available under `/v1/searches/{search_id}`. `POST /v1/experiments` records evidence-aware experiments and `/v1/experiments/{experiment_id}` retrieves them. If `ARCHAI_API_KEY` is configured, write operations require the `x-api-key` header. Generator and expensive job endpoints remain disabled until authenticated deployment configuration and a real checkpoint are present.
