# ArchAI Studio Space

This Space is intentionally evidence-only. Configure `ARCHAI_GENERATOR_CHECKPOINT`,
`ARCHAI_GENERATOR_CHECKPOINT_SHA256`, `ARCHAI_MODEL_MANIFEST`, and
`ARCHAI_DATASET_MANIFEST` with released artifacts and provenance manifests before
publishing. The status view verifies configured checkpoint/model hashes and does not
invent benchmark or training metrics when those artifacts are absent.
